# Examples

- `minimal.ini` is the smallest useful manifest and relies on the implicit `general` group.
- `all-types.ini` demonstrates every format-1 field type.
- `schema.rabbit-fallback.ini` is Rabbit's generic schema-settings manifest at the source revision recorded in
  `PROVENANCE.md`.

Labels and descriptions are literal text in format 1. The examples use English except for Rabbit's original fallback
manifest, which intentionally remains unchanged as a compatibility artifact.
